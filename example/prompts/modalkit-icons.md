# modalkit example — Section Glyphs

One glossy 3D glyph per showcase section, in the Hutch house style with modalkit's violet accent.

Save to: assets/icons

## House Style

```
Modern macOS-style app glyph, soft 3D rendering with subtle volumetric shading,
rounded glossy edges, gentle inner glow. Single subject, centered, filling ~78%
of the frame. Primary accent color violet (#7C5CFF) with soft lavender
highlights; designed to sit on a dark UI. IMPORTANT: the subject is fully
isolated on a 100% transparent background — real alpha channel, absolutely no
backdrop, no gradient, no floor, no studio background, no shadow plate, no
border, no text. Cut-out sticker style. Output: 1024×1024 PNG, transparent.
```

---

## 1. Sheets — `sheets.png`

```
A bottom sheet rising from the lower edge: a rounded-top translucent violet
panel with a small horizontal drag-handle pill near its top edge, slightly
tilted in 3D, a second thinner sheet peeking behind it to suggest stacking.
```

## 2. Fullscreen — `fullscreen.png`

```
A glossy 3D picture frame expanding to fullscreen: a rounded-corner violet
frame with four small outward-pointing corner arrows, holding a tiny stylized
mountain-and-sun photo, floating with slight perspective.
```

## 3. Dialogs — `dialogs.png`

```
Two overlapping rounded speech-bubble cards in 3D: the front one violet with a
soft glowing exclamation-free blank face and a small OK-style pill button
embossed on it, the back one lavender, both with rounded glossy edges.
```

## 4. Architectural — `architectural.png`

```
Three stacked rounded 3D layers like a layered stack diagram: bottom layer
deep violet, middle lavender, top glowing light violet slightly lifted with a
gap, suggesting stacked modals and layered architecture, gentle isometric tilt.
```

## 5. Settings — `settings.png`

```
A glossy 3D gear in violet with softly rounded teeth, a smaller lavender gear
tucked behind its upper right, subtle inner glow at the hub.
```
